# Appliance Repair Appointment Booking

This is a simple Flask web application that allows customers to book service appointments for an appliance repair business.

## Setup

1. Create a virtual environment and install dependencies:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

2. Run the application:
   ```bash
   python app.py
   ```

The app will be available at `http://localhost:5000`.

## Running Tests

Run the unit tests with:
```bash
pytest -q
```
